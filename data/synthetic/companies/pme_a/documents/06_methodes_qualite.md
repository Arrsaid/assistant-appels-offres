# Méthodes de réalisation et qualité

> DONNÉES SYNTHÉTIQUES — ENTREPRISE FICTIVE — usage de test uniquement.
> Dossier : PME A — Atelier Portail (nom de scénario). Version 1.0, situation au 18 septembre 2026.

## Déroulement

1. Atelier de cadrage : objectifs, utilisateurs, interfaces, hypothèses et critères de recette.
2. Audit de l’existant pour les reprises : dépendances, tests, dette technique et accès nécessaires.
3. Découpage en lots ; priorisation avec le client ; démonstrations toutes les deux semaines.
4. Revue de code par un autre développeur et contrôles automatiques avant fusion.
5. Tests unitaires ciblés, tests d’intégration et scénarios de parcours critiques.
6. Recette sur environnement dédié ; suivi des anomalies et validation du client avant livraison.
7. Documentation, transfert et passage en maintenance.

## Livrables

Backlog, journal des décisions, code source, documentation d’installation, résultats de tests et compte rendu de recette.

## Limites

Les contrôles automatiques ne constituent pas un audit d’accessibilité complet ni un audit de sécurité indépendant. Aucun taux de couverture de tests ou résultat d’audit réel n’est fourni dans ce dossier.
